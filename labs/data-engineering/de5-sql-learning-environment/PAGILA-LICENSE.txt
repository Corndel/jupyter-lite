pagila.sqlite holds the Pagila sample database, loaded by generate_db.py from
devrimgunduz/pagila (https://github.com/devrimgunduz/pagila), commit
5ba5a57aeb159f75f02aca2432d3c262186d13d3: the same pagila-schema.sql and
pagila-data.sql as Corndel/DE-sql-learning-environment-AWS. Pagila is a
PostgreSQL port of the Sakila sample database, which Mike Hillyer of the
MySQL AB documentation team developed. Pagila's licence follows.
